Methods and sources

cm/360 = 360 × 2.54 / (DPI × sensitivity × yaw). Target sensitivity = source DPI × source sensitivity × source yaw / (target DPI × target yaw). These equations equate degrees per physical inch.

Research reviewed November 10, 2026. Original implementation; no upstream code copied.

  • Valve Source SDK: input rotation and m_yaw default
  • Microsoft UF2 specification: 512-byte blocks and magic values
  • QMK flashing documentation: hardware-specific firmware context (this tool never flashes)
  • MDN StereoPannerNode: equal-power stereo panning

Firmware parsing is deliberately limited to header candidates, not full UF2 validation. Unknown containers are not rejected as invalid firmware. No hardware measurements or universal game support are claimed.
